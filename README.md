# 재정경제부 언론 모니터링

재정경제부(가상) 언론 담당자를 위한 **로컬 전용 단일 사용자** 뉴스 모니터링 도구입니다.
네이버 뉴스 검색 API로 설정된 키워드를 하루 여러 번 자동 수집하고, 기사를 소제목별로
자동 분류해 브라우저 화면(정적 HTML)으로 보여줍니다. 외부 AI(LLM) API는 쓰지 않고,
분류·요약·키워드 추출을 모두 규칙 기반(단어 빈도)으로 처리합니다.

## 주요 기능

- **자동 수집**: 설정한 시각(기본 09:00/10:30/13:30/16:30, 설정에서 자유롭게 편집 가능)에
  네이버 뉴스 검색 API로 키워드를 검색해 당일(KST) 기사만 수집
- **자동 소제목 분류**: 기사 요약(description)에 자주 등장하는 단어로 소제목을 매 회차
  새로 생성(최대 5개), 규칙 기반이라 LLM 비용 없음
- **언론사 우선순위 정렬**: 방송사 → 주요 언론사 → 그 외 순, 설정에서 언론사 화이트리스트와
  순서를 직접 지정 가능
- **사진기사 자동 제외**: 포토/사진/화보 등 힌트 단어가 있으면 제외([속보]는 예외)
- **기사 큐레이션**: 개별 기사 숨기기/되돌리기, ↑/↓ 버튼으로 순서 조정(소제목 경계
  넘나들기 포함), 소제목 이름 직접 바꾸기
- **출력 형식 커스터마이징**: `ㅇ (언론사) 기사제목` 줄 형식을 자리표시자 템플릿으로 변경 가능
- **진입 화면**: 로고 + 당일 주요 키워드 워드클라우드(무궁화 연상 방사형 배치)
- **지난 기사 조회**: 최근 7일간 회차를 날짜별 → 시간대별로 조회 (7일 지나면 자동 삭제)
- **클립보드 복사 / .txt 내보내기**, **1분 자동 새로고침**

## 아키텍처

서버 프레임워크 없이 파이썬 스크립트가 결과를 정적 HTML 파일(`index.html`,
`history.html`, `home.html`)로 생성하고 브라우저로 엽니다. 설정 저장(키워드 변경, 기사
숨기기 등)을 위한 최소 로컬 HTTP 서버(`app/settings_server.py`, `127.0.0.1`에서만 동작)
하나만 예외로 둡니다. 데이터는 SQLite 대신 로컬 JSON 파일(`data/`)에 저장합니다.

자세한 설계는 [DESIGN.md](DESIGN.md), 전체 요구사항은 [PRD.md](PRD.md), 작업 이력은
[PLAN.md](PLAN.md)를 참고하세요.

## ⚠️ 로컬 전용 도구입니다 (인터넷 배포 불가)

이 앱은 처음부터 "내 컴퓨터에서만 실행"을 전제로 설계됐습니다:

- 스케줄러가 앱이 켜진 동안 계속 도는 무한 루프 구조라, 서버리스(Vercel 등) 환경에서
  실행할 수 없습니다.
- 기사·설정 데이터를 로컬 파일에 저장하므로, 서버리스 환경에서는 배포마다 초기화됩니다.
- 설정 저장 서버에 **로그인/인증이 없습니다** — "로컬에서만 접속 가능"을 전제로 의도적으로
  만들지 않았습니다. 인터넷에 그대로 노출하면 누구나 로그인 없이 키워드 변경, 기사 삭제 등이
  가능해집니다.

따라서 이 저장소를 그대로 Vercel 등에 배포하지 마세요. 인터넷 공개가 필요하면 별도의
아키텍처 재설계(실제 데이터베이스, 서버리스 스케줄, 인증 추가)가 필요합니다.

## 설치 및 실행

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`.env` 파일을 만들어 네이버 뉴스 검색 API 키를 넣습니다 (네이버 개발자센터에서 발급):

```
NAVER_CLIENT_ID=발급받은_클라이언트_ID
NAVER_CLIENT_SECRET=발급받은_클라이언트_시크릿
```

실행:

```bash
python3 main.py
```

브라우저가 자동으로 열리며 진입 화면(`home.html`)을 보여줍니다. 설정은
`http://127.0.0.1:8765/`에서 변경할 수 있습니다.

## 테스트

```bash
python3 tests/test_integration.py
```

## 기술 스택

- Python 3.9+, `requests`, `python-dotenv`
- 외부 프레임워크 없음 (FastAPI/Django 미사용), 표준 라이브러리 `http.server`만 사용
- 순수 CSS 기반 UI, 자바스크립트는 클립보드 복사·기사 숨기기/순서 조정/소제목 이름
  바꾸기 등 꼭 필요한 곳에만 최소로 사용
